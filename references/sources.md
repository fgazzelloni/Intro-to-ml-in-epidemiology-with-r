# Sources and further reading

Accessed 27 September 2026 unless otherwise noted.

## Data

- Centers for Disease Control and Prevention. [NNDSS Weekly Data](https://data.cdc.gov/NNDSS/NNDSS-Weekly-Data/x9gk-5huc). Dataset identifier `x9gk-5huc`.
- Centers for Disease Control and Prevention. [Notifiable Infectious Disease Data Tables](https://www.cdc.gov/nndss/infectious-disease/). Explains that weekly data are provisional and annual data are finalized.
- Centers for Disease Control and Prevention. [Notice to Data Users and Publication Criteria](https://www.cdc.gov/nndss/infectious-disease/notice-to-data-users.html).
- Centers for Disease Control and Prevention. [Historic West Nile Virus Data](https://www.cdc.gov/west-nile-virus/data-maps/historic-data.html). Describes ArboNET and limitations of surveillance data.

## Methods

- Wright MN, Burk L, Golchian P, Kapar J, Koenen N, Langbein SH. [Machine Learning in Epidemiology](https://arxiv.org/abs/2602.16352). 2026.
- [`mlr3` documentation](https://mlr3.mlr-org.com/).
- [`mlr3` custom resampling](https://mlr3.mlr-org.com/reference/mlr_resamplings_custom.html).
- [Applied Machine Learning Using `mlr3` in R](https://mlr3book.mlr-org.com/).
- Gazzelloni F. *Health Metrics and the Spread of Infectious Diseases: Machine Learning Applications and Spatial Modelling Analysis with R*. CRC Press; 2025.
